Run the application locally

This GitHub Pages homepage is a project overview, not the full running backend/frontend. Follow the repository README for the actual setup.

Before starting: check that the project’s frontend and backend directories are present in the repository. Create your local .env from .env.example; never commit API keys, passwords or real credentials.
1. Get the source

Clone or download the repository and read the installation prerequisites in README.md.

2. Configure services

Set up the required environment variables. Use demo mode first if supported by the project.

3. Start and verify

Follow the documented commands, then check the local health endpoint and API docs if the backend starts successfully.
